Sandbox sprite sources
======================

These sandbox sprites use free/open icon assets with permissive licenses:

- `shovel-top.svg`  
  Source: Lucide icon `shovel`  
  URL: https://raw.githubusercontent.com/lucide-icons/lucide/main/icons/shovel.svg  
  License: ISC

- `shell-clam.svg`  
  Source: Lucide icon `shell`  
  URL: https://raw.githubusercontent.com/lucide-icons/lucide/main/icons/shell.svg  
  License: ISC

- `shell-spiral.svg`  
  Source: Tabler icon `spiral`  
  URL: https://raw.githubusercontent.com/tabler/tabler-icons/master/icons/outline/spiral.svg  
  License: MIT

Local modifications were applied for color and rendering fit in the sandbox game.
